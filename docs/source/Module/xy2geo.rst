xy2geo
========================

:简介: 将局部 north/east 坐标转换为纬度/经度坐标


语法
-----------

**grt xy2geo**
|-G|\ *ingrid* | **-Q**\ *infile*
|-O|\ *outfile*
|-C|\ *lat0/lon0*
[ **-h** ]


描述
--------

**xy2geo** 模块使用参考点处的局部切平面近似，将局部笛卡尔坐标转换为地理坐标。
输入可以是静态解 NetCDF 文件，也可以是坐标文本文件，输出保存到新的文件中。
输入文件不会被修改。

局部坐标 **north** 和 **east** 的单位为 km。
**-C** 指定参考点的纬度和经度，格式为 *lat0/lon0*，单位为 degree。
参考点会作为新的 NetCDF 全局属性 **lat0** 和 **lon0** 写入输出文件。

模块采用参考纬度处的局部切平面近似：

.. math::

    \mathrm{lat} = \mathrm{lat}_0 + \frac{\mathrm{north}}{R\pi/180}

    \mathrm{lon} = \mathrm{lon}_0 + \frac{\mathrm{east}}{R\cos(\mathrm{lat}_0)\pi/180}

其中 :math:`R=6371` km。
输出经度规范化到 ``[-180, 180)``，因此参考点在经度边界附近时仍可正确处理东西方向跨界的情况。
极点附近的坐标转换不在本模块的适用范围内。

对于 **grid** 布局，模块将 **north** 维度和坐标变量重命名为 **lat**，
将 **east** 维度和坐标变量重命名为 **lon**。
对于普通 **points** 布局和有限接收断层布局，模块保留 **point** 和 **nfault** 维度，
仅将一维坐标变量 **north(point)** 和 **east(point)** 重命名为 **lat(point)** 和 **lon(point)**。
其他变量、维度、属性和数据都会复制到输出文件中。

使用 **-Q** 时，输入文本的每个数据行前两列分别视为 **north** 和 **east**，
后续列按原字符串保留。
空行和以 ``#`` 开头的注释行会原样复制。
输出文件最前面会增加 ``# lat0 lon0`` 题头，用于记录参考点。


必选选项
----------

.. _-G:

**-G**\ *ingrid*
    输入静态解 NetCDF 文件。
    文件应包含 **layout** 全局属性，以及局部坐标变量 **north** 和 **east**。
    **-G** 与 **-Q** 不能同时使用。

.. _-Q:

**-Q**\ *infile*
    输入坐标文本文件。
    模块只读取每个数据行的前两列，分别作为 **north** 和 **east**。
    **-G** 与 **-Q** 不能同时使用。

.. _-O:

**-O**\ *outfile*
    输出 NetCDF 或文本文件路径。
    输出文件必须与输入文件不同。

.. _-C:

**-C**\ *lat0/lon0*
    局部坐标原点的纬度和经度，单位为 degree。
    纬度范围为 ``(-90, 90)``，经度范围为 ``[-180, 180]``。

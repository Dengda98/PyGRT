lamb2
==============

:简介: 使用广义闭合解求解第二类 Lamb 问题

语法
-----------

**grt lamb2**
|-P|\ *nu*
|-T|\ *t1/t2/dt*
|-D|\ *theta*
|-A|\ *azimuth*
[ **-h** ]


描述
--------

第二类 Lamb 问题指震源位于地下、观测点位于地表的情形。**lamb2** 模块
按照《地震学中的 Lamb 问题（下）》第 7.4 节的步骤，使用 P、S1、S2 和
S-P 四个积分项的广义闭合解，计算阶跃力产生的无量纲位移及其源点一阶
空间导数和接收点一阶空间导数。三个结果在同一次计算中同时得到，其中接收点
坐标导数的水平两个方向利用平移不变性，竖直方向利用自由表面边界关系

输出第一列为无量纲时间，随后为 9 个 :math:`G_{ij}` 分量、27 个源点坐标
导数分量和 27 个接收点坐标导数分量，三组分量均按行优先顺序排列，源点导数列
在前，接收点导数列在后。所有输出均为无量纲量，实际物理量的恢复关系为

.. math::

   G^H=\frac{\bar{G}^H}{\pi^2\mu r},\qquad
   G^H_{,k'}=\frac{\bar{G}^H_{,k'}}{\pi^2\mu r^2},\qquad
   G^H_{,k}=\frac{\bar{G}^H_{,k}}{\pi^2\mu r^2}

其中 :math:`r` 为震源到接收点的距离，:math:`\mu` 为剪切模量，:math:`\mu` 和
:math:`r` 应与目标物理量采用一致的单位。恢复实际振幅时，需要在程序外部提供
:math:`\mu`。

必选选项
--------------

.. _-P:

**-P**\ *nu*
    半空间的泊松比 *nu*，要求范围在 (0, 0.5)。

.. _-T:

**-T**\ *t1/t2/dt*
    无量纲时间序列 :math:`\bar{t}`，根据起点时刻 *t1*、终点时刻 *t2* 和间隔
    *dt* 定义

.. _-D:

**-D**\ *theta*
    震源射线角，单位为度，从震源指向观测点的射线与竖直向上方向的夹角，
    要求范围在 (0, 90)

.. _-A:

**-A**\ *azimuth*
    方位角，单位为度，从震源指向观测点

syn
==============

:简介: 指定震源机制，根据动态格林函数合成三分量位移（及其空间导数）

语法
-----------

**grt syn** 
|-G|\ *grndir*
|-A|\ *azimuth*
|-S|\ [**u**]\ *scale*
|-O|\ *outdir*
[ **-Ds**\ *depsrc* ] [ **-Dr**\ *deprcv* ] [ |-R|\ *dist* ]
[ |-F|\ *fn/fe/fz* ]
[ |-M|\ *strike/dip/rake* ]
[ |-T|\ *Mxx/Mxy/Mxz/Myy/Myz/Mzz* ]
[ |-D|\ *tftype/tfparams* ]
[ |-I|\ *odr* ]
[ |-J|\ *odr* ]
[ |-N| ]
[ **-e** ]
[ **-s** ]
[ **-h** ]


描述
--------

**syn** 模块默认合成的是脉冲型 （impulse-like）位移，单位 cm。三分量位移分别为：

+ **Z** - 垂直向上
+ **R** - 径向向外
+ **T** - 沿 **R** 方向顺时针旋转 90 °

保存 SAC 文件路径为 ``{outdir}/{ch}.sac``，其中 ``ch`` 为分量名。
若设置 |-N| 则输出为 ZNE 分量，其中 Z 不变，N 和 E 分别为北向和东向。

目前合成位移支持的震源类型包括爆炸源(|-S|)，单力源(|-F|)，剪切源/张裂源(|-M|)和矩张量源(|-T|)，
其中张裂源/矩张量源是根据爆炸源和剪切源合成的。一次只能选择一种震源。



必选选项
----------

.. _-G:
    
**-G**\ *grndir*
    可以传入 :doc:`greenfn` 输出的单个震中距子目录，此时该子目录已经指定了震源深度、
    台站深度和震中距，不能再设置 **-Ds/-Dr/-R**。也可以传入动态格林函数输出根目录，
    此时当格林函数库包含多个震源深度、台站深度或震中距时，必须分别设置对应的
    **-Ds**、**-Dr** 或 **-R**；如果对应维度只有一个值，则可以省略该选项。程序按
    SAC 头段中的深度和震中距精确选择子目录，不进行任何插值。单值维度的选项可以省略，
    也可以显式设置，但显式设置的值必须与根目录中的对应值一致。

.. _syn-dynamic-depth:

**-Ds**\ *depsrc*
    根目录模式下使用的震源深度 (km)。当格林函数库包含多个震源深度时必须设置；
    只有一个震源深度时可以省略，也可以显式设置。指定不存在的深度会报错；
    如果传入子目录则不能设置该选项。

**-Dr**\ *deprcv*
    根目录模式下使用的台站深度 (km)。当格林函数库包含多个台站深度时必须设置；
    只有一个台站深度时可以省略，也可以显式设置。指定不存在的深度会报错；
    如果传入子目录则不能设置该选项。

.. _-R:

**-R**\ *dist*
    根目录模式下的精确震中距 (km)。当格林函数库包含多个震中距时必须设置；
    只有一个震中距时可以省略，也可以显式设置。指定不存在的震中距会报错；
    如果传入子目录则不能设置该选项。不能使用距离插值。

.. _-A:

**-A**\ *azimuth*
    方位角，单位°，北向为 0 °

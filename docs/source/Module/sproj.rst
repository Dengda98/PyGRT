sproj
=========

:简介: 根据接收断层形态将动态应力张量投影为法向应力变化和剪应力变化


语法
-----------

**grt sproj**
|-G|\ *syn_dir*
[ |-M|\ *geometry* | |-Q|\ *file* ]
[ **-h** ]


描述
--------

:doc:`sproj` 模块读取 :doc:`stress` 生成的六个应力张量分量。
根据接收断层的走向、倾角和滑动角，计算每个接收点的法向应力变化
:math:`\Delta \sigma_\text{n}` (**sigma_n**) 和沿 rake 方向的剪应力变化 :math:`\Delta \tau_\text{s}` (**tau_s**)，
结果保存到输入目录中的 **sigma_n.sac** 和 **tau_s.sac**。

**sigma_n** 采用张开为正的约定， **tau_s** 是牵引力在接收断层滑动方向上的有符号投影，
与 rake 方向同向为正。结果单位与输入应力相同，即 dyne/cm²（0.1 Pa）。

接收断层形态可以通过以下方式指定：

* 默认使用合成结果 SAC 头段中保存的形态
* 普通接收点可用 |-M| 统一指定形态，或用 |-Q| 逐点指定形态；
  SAC 头段没有完整形态时，必须选择其中一种
* 有限接收断层保留已有走向和倾角，可用 |-M| 补充或替换滑动角


必选选项
----------

.. _-G:

**-G**\ *syn_dir*
    包含六个 **stress_??.sac** 分量的单台目录或多台根目录。
    多台结果逐接收目录计算并保存。


可选选项
----------

.. _-M:

**-M**\ *geometry*
    手动指定接收断层形态，角度单位为 °。
    普通接收点使用 *strike/dip/rake*，所有点使用同一形态。
    有限接收断层使用 *rake* 补充未定义的滑动角，
    或使用 *rake+f* 强制所有点使用该滑动角。

.. _-Q:

**-Q**\ *file*
    为普通接收点逐点指定形态，每行依次为 *north east depth strike dip rake*，
    坐标单位为 km，角度单位为 °。点数、坐标和顺序须与输入结果一致，
    多台结果按子目录的数字索引排序。与 |-M| 互斥，不用于有限接收断层。
    指定单个接收目录时，文件也须只包含对应的一个点。
    所有接收坐标均在写出结果前核对；坐标以 SAC 头段为准，不能使用舍入后的目录名代替。

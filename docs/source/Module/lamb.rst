lamb
==============

:简介: 组合三类 Lamb 闭合解，直接计算均匀弹性半空间中的动态全波解

语法
-----------

**grt lamb** （点源）
|-H|\ *vp/vs/rho*
|-N|\ *nt/dt*
**-Ds**\ *depsrc*
|-S|\ [**u**]\ *scale*
|-O|\ *outdir*
( |-R|\ *dist* |-A|\ *azimuth* **-Dr**\ *deprcv* | |-Q|\ *file* | |-U|\ *faultparam* )
[ |-F|\ *fn/fe/fz* | |-M|\ *strike/dip[/rake]* | |-T|\ *Mxx/Mxy/Mxz/Myy/Myz/Mzz* ]
[ |-D|\ *tftype*\ [/*tfparams*][**+d**\ *delay*] ]
[ |-E|\ [**p**]\ *t0*\ [/*v0*] ] [ |-I|\ *odr* ] [ |-J|\ *odr* ]
[ **-n** ] [ **-e** ] [ **-s** ] [ |-L|\ *phases* ] [ |-P|\ *nthreads* ] [ **-h** ]

**grt lamb** （有限断层）
|-H|\ *vp/vs/rho*
|-N|\ *nt/dt*
|-C|\ *faultparam*
|-O|\ *outdir*
( |-R|\ *dist* |-A|\ *azimuth* **-Dr**\ *deprcv* | |-Q|\ *file* | |-U|\ *faultparam* )
[ |-D|\ *tftype*\ [/*tfparams*][**+d**\ *delay*] ]
[ |-E|\ [**p**]\ *t0*\ [/*v0*] ] [ |-I|\ *odr* ] [ |-J|\ *odr* ]
[ **-e** ] [ **-s** ] [ |-L|\ *phases* ] [ |-P|\ *nthreads* ] [ **-h** ]


描述
--------

调用 :doc:`lamb` 时，需要确定以下五类信息：

#. **介质与采样**：|-H| 指定均匀半空间参数，|-N| 指定采样点数和时间间隔，无需格林函数库
#. **震源位置**：点源位于水平原点，必须用 **-Ds** 指定深度；有限震源用 |-C| 读取断层文件
#. **台站位置**：用 **-R/-A/-Dr** 指定一个接收点，三个选项都需设置；
   或用 |-Q| 读取任意点列表，或用 |-U| 读取有限接收断层，三种方式选其一
#. **震源机制与强度**：点源用 |-S| 设置强度，机制可选 |-M|、|-F| 或 |-T|，默认爆炸源；
   有限震源由 |-C| 提供位置、机制和强度，不能再设置 **-Ds/-S/-M/-F/-T**
#. **输出**：|-O| 指定 SAC 输出目录，**-n** 选择 ZNE 分量，**-e** 增加位移空间导数；
   有限震源始终输出 ZNE

所有坐标共用一个水平原点。
模块根据源点和接收点深度自动选择 Lamb 闭合解：两点都在自由表面时使用第一类解，
只有一个点位于地下时使用第二类解，两点都位于地下时使用第三类解。
所有源台组合的水平距离都须大于零。
两点都在自由表面时仅支持单力源 |-F|；地表单力源且所有接收点都在地表时， **-e** 被忽略。

位移单位为 cm，默认 Z 垂直向上，R 径向向外，T 沿 R 顺时针旋转 90°，
N、E 分别为北向、东向。

.. include:: explain_dynamic_output.rst_

可用 |-D| 设置震源时间函数，|-E| 调整记录起点，SAC 头段 **t0/t1** 记录最早 P、S 初至。
本模块使用线性卷积，并裁剪到输出时窗，须使时窗覆盖所需震相和卷积尾部。


必选选项
----------

.. _-H:

**-H**\ *vp/vs/rho*
    均匀半空间参数。*vp* 和 *vs* 的单位为 km/s，*rho* 的单位为 g/cm\ :sup:`3`。

.. _-N:

**-N**\ *nt/dt*
    最小输出采样点数 *nt* 和采样间隔 *dt* (s)。默认从发震时刻开始记录。
    震源过程（含破裂延迟）较长时会自动延长记录，所有接收点的采样点数一致。

.. include:: explain_-S.rst_

.. _-O:

**-O**\ *outdir*
    输出目录名，不存在时自动新建。已有同名文件会被覆盖。


可选选项
--------

.. _-Ds:

**-Ds**\ *depsrc*
    点源的震源深度 (km)，允许取 0。点源模式必须设置，使用 |-C| 时不能设置。

.. _-Dr:

**-Dr**\ *deprcv*
    单个接收点的深度 (km)，允许取 0。使用 |-Q|、|-U| 时不能设置。

.. _-R:

**-R**\ *dist*
    接收点相对水平原点的距离 (km)，须为正数。使用 |-Q|、|-U| 时不能设置。

.. _-A:

**-A**\ *azimuth*
    接收点相对水平原点的方位角，单位为 °，北向为 0°，取值范围为 [0, 360]。
    使用 |-Q|、|-U| 时不能设置。

.. include:: explain_-Q.rst_

.. include:: explain_-Ufault.rst_

.. include:: explain_-Cfault.rst_

.. include:: explain_src.rst_

.. include:: explain_-Dtfunc.rst_

.. _-E:

**-E**\ [**p**]\ *t0*\ [/*v0*]
    设置输出记录的起点，最终取最近的采样时刻，默认起点为 0：

    * **-E**\ *t0*：起点为 *t0* (s)
    * **-E**\ *t0/v0*：起点为 :math:`t_0+d_{\min}/v_0`，
      :math:`d_{\min}` 为有效子源到当前接收点的最短直线距离（含深度差），
      *v0* 为参考速度 (km/s)
    * **-Ep**\ *t0*：起点为当前接收点的最早 P 初至（含破裂延迟）加 *t0*，*t0* 须为负数

.. include:: explain_-IJ.rst_

.. _-L:

**-L**\ *phases*
    仅保留指定震相项，用逗号分隔 *P*、*S*、*R*、*PP*、*SS*、*PS*、*SP* 和 *sPs*。
    可用震相由每个源台对的位置决定：两点都在地表时为 *P/S/R*；
    地下源、地表接收时为 *P/S/SP*，地表源、地下接收时为 *P/S/PS*；
    两点都在地下时为 *P/S/PP/SS/PS/SP/sPs*。
    不支持的震相会被忽略，没有有效震相时输出全零波形。
    该选项不改变 SAC 头段的几何初至标记。

.. include:: explain_-P.rst_

**-n**
    将输出分量设置为 ZNE，默认为 ZRT。注意本模块使用小写 **-n**。

**-e**
    同时计算位移空间导数，文件名在分量名前增加导数方向前缀，
    例如 *zN.sac* 表示北向位移对接收点 z 坐标的偏导。
    ZRT 使用 **z/r/t** 前缀，角向项为 :math:`r^{-1}\partial_\theta`；
    ZNE 使用 **z/n/e** 前缀，z 向上。未进行时间积分或微分时，导数单位为 1。

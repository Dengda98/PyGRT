(21) 动态全波解与静态解的自洽对比
------------------------------------------------

下载示例： :download:`ex21.tar.gz`

震源激发完成后，动态位移应随振动衰减趋近相同震源的静态位移。
本例使用一个剪切点源，震源深度为 3 km，台站位于地表，震中距为 10 km，方位角为 60°。
震源机制为 strike/dip/rake = 33°/50°/120°，标量地震矩为 :math:`10^{24}` dyne·cm。

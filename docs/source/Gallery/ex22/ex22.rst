(22) 有限断层剖分尺度对合成波形的影响
--------------------------------------------------------------------------------

下载示例： :download:`ex22.tar.gz`

本例采用 :doc:`/Module/faultdiv` 模块剖分有限断层，再用 :doc:`/Module/lamb` 模块计算均匀半空间中的位移闭合解，
比较不同剖分尺度对合成波形的影响，复现了 **《地震学中的 Lamb 问题（下）》** (|zhang2024|) 中的结果。

均匀半空间的介质参数为 :math:`V_P=8.0` km/s、:math:`V_S=4.62` km/s、
:math:`\rho=3.3` g/cm\ :sup:`3`。
断层长 20 km、宽 10 km，上缘中心位于地表原点，最终滑动量为 1 m，
破裂速度为 3.5 km/s，各子断层的滑动量在 0.5 s 内线性增加至最终值。

左旋走滑断层的 strike/dip/rake 为 45°/90°/0°，沿正走向单侧破裂；
逆冲断层为 90°/45°/90°，由下缘向上缘破裂。
接收点的 **(North, East, Depth) = (20, 0, 2) km**。
另设同一水平位置的地表接收点作为对照，以下分别展示两种断层及接收点的分布。

波形中的 :math:`u_1,u_2,u_3` 分别为北、东、下向位移，单位为 cm。
各曲线沿纵轴错开显示，标注对应剖分尺寸，标尺表示 5 cm。
灰色粗线为最细网格在地表接收点 **(20, 0, 0) km** 的结果。
随着剖分尺度减小，波形逐渐平滑。
示例中使用的波形时间间隔不够细，读者可自行测试间隔更细的结果。
